## 项目概述
这是一个用C++编写的简化版Redis服务器项目，采用异步非阻塞I/O模型，实现了基本的键值存储功能。

## 已完成部分 ✅

### 1. 核心数据结构

#### 缓冲区管理 (buffer.h, buffer.cpp)
- **Buffer结构**: 使用指针优化的环形缓冲区实现
- **功能**:
  - 数据追加 (buf_append)
  - 数据消费 (buf_consume)
  - 支持多种数据类型追加 (uint8, uint32, int64, double)
  - 自动扩容和内存重排
- **状态**: ✅ 完整实现
- **测试覆盖**: ✅ 有完整测试文件 (test_buffer_complete.cpp)

#### 哈希表 (hashtable.h, hashtable.cpp)
- **特性**:
  - 渐进式rehashing机制
  - 侵入式数据结构设计
  - 支持增删改查操作
- **核心功能**:
  - hm_insert: 插入节点
  - hm_lookup: 查找节点
  - hm_delete: 删除节点
  - hm_foreach: 遍历所有节点
- **状态**: ✅ 完整实现
- **测试覆盖**: ✅ 有测试文件 (test_hashtable.cpp)

#### AVL树 (avltree.h, avltree.cpp)
- **特性**:
  - 自平衡二叉搜索树
  - 支持按偏移量查找
  - 维护子树大小信息
- **核心功能**:
  - avl_fix: 平衡调整
  - avl_del: 节点删除
  - avl_offset: 按偏移查找
- **状态**: ✅ 完整实现
- **测试覆盖**: ✅ 有完整测试文件 (test_avl_complete.cpp)

#### 有序集合 (zset.h, zset.cpp)
- **特性**:
  - 结合哈希表和AVL树
  - 支持按分数排序
  - O(log n)时间复杂度操作
- **核心功能**:
  - zset_insert: 插入元素
  - zset_lookup: 查找元素
  - zset_delete: 删除元素
  - zset_lookge: 范围查找
- **状态**: ✅ 完整实现

### 2. 网络服务器 (server.cpp)

#### 服务器架构
- **模型**: 单线程 + poll异步I/O
- **协议**: 自定义二进制协议
- **连接管理**: 基于poll的事件循环
- **端口**: 1234

#### 已实现的Redis命令
- **GET**: 获取键值 ✅
- **SET**: 设置键值 ✅
- **DEL**: 删除键 ✅
- **KEYS**: 列出所有键 ✅

#### 协议支持
- **请求解析**: 完整的二进制协议解析
- **响应编码**: 支持多种数据类型(NIL, STR, INT, DBL, ERR, ARR)
- **管道化**: 支持请求管道处理
- **数据类型支持**: 字符串(T_SIR)和有序集合(T_ZSET)

### 3. 工具函数 (common.h)
- **哈希函数**: FNV哈希算法实现
- **容器宏**: container_of宏用于侵入式数据结构

### 4. 编译系统
- **Makefile**: 完整的编译配置
- **目标文件管理**: 自动化obj目录管理
- **测试支持**: 独立测试编译

## 编译和运行

### 使用Makefile编译
```bash
# 编译项目
make

# 清理编译文件
make clean

# 编译并运行
make run

# 查看帮助
make help
```

### 手动编译
```bash
# 手动编译
g++ -Wall -Wextra -std=c++11 -g -O2 -Iinclude src/*.cpp -o server

# 运行
./server
```

项目的基础架构非常扎实，数据结构实现优秀，但在命令完整性和高级功能方面还有很大提升空间。
